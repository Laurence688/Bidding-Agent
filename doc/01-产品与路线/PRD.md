# Laura 产品说明

Laura 面向需要根据产品资料组织投标应答的用户，把条款、型号、证据、判断和英文口径连接起来，并保留人工审核。

## 核心能力

- 项目与会话：隔离对话与任务，设置默认产品，绑定知识库，支持项目回收与恢复。
- 产品与知识：明确产品名称和别名，解析产品 Word、文字型 PDF 与 Excel，预览切片、构建本地索引并发布版本。
- 问答与应标：产品问答、单条 SOC、Excel 批处理；展示处理步骤、结果、来源和审核状态。
- 文档工具：独立标书拆解、文本与文件翻译，不混入 SOC 规则。
- 观测与评测：查看任务状态、调用与证据过程，以人工标注检查质量。

## 判定与交付边界

FC、PC、NC、UNKNOWN 四态必须保留。UNKNOWN 不等于 NC；缺少适用证据不能当作产品明确不支持。正式交付要求解决 UNKNOWN、核对证据及型号、通过人工审核与导出门禁。

资料和索引在本地管理；云端生成需要使用者配置接口和明确联网。演示与工程回归不能证明真实业务准确率、引用质量、速度或成本收益。
