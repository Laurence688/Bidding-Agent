# 界面与交互说明

顶部导航按工作中心、数据管理、效果评估、效率工具、文档中心和系统设置组织。当前项目决定会话、任务和知识范围；会话侧栏用于切换与管理对话，工作区保留必要草稿。

首次创建项目若无产品，应通过可点击入口完成登记，回来后继续创建。表单错误应靠近输入，可关闭并随编辑清除；不能让一次失败长期占据所有页面。

知识库采用“上传 → 切分 → 预览 → 向量化 → 发布”的显式流程。构建后台运行，通知显示进度，关闭通知不取消任务。项目回收站提供可恢复操作，运行任务存在时明确阻拦。

模型设置区分接口草稿、已保存配置和当前生成接口。校验只使用保存值；联网授权单独明确保存，不随着填 Key 自动开启。文档中心提供目录、搜索、正文和来源跳转；公开文档只包含使用与现行设计说明。
