# 运行观测与评测说明

任务记录用于查看状态、步骤、失败原因、模型调用、用量与耗时。接口连接成功、模型返回成功、流程执行成功、业务结论正确是不同层次，不应互相替代。

质量核对关注要求是否完整、数值与条件是否保留、检索是否命中适用资料、引用是否足以支持结论、四态是否合理和英文口径是否越过证据边界。人工标注和固定样本可用于比较不同配置，但需要记录样本、版本与判定标准。

本地记录默认保存在使用者本机。LangSmith 等外部同步使用独立设置，只有明确启用才进行相应同步；生成 API 联网许可不会自动开启观测同步。

本公开文档说明机制，不包含作者的历史测试、日志、验收结果或业务数据，也不据工程回归宣称业务准确率、速度或成本收益。
