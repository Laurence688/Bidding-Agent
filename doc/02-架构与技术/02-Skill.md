# Skill

出版版本：v0.4.6

项目内的 Skill 是一份共享证据规范。默认内容来自 soc-evidence.md，由提示词渲染器与当前节点模板一起拼入系统消息。设置页的「共享规则」随整个 Prompt 配置包保存，并进入任务快照。

## 规范约束的判断

- **证据适用性**　确认具体型号与条件。能力资料可以说明产品支持某项能力，实际供货、许可证或现场配置需要对应的项目事实。
- **引用与原文**　保留数字、单位、术语和逻辑条件。引用可定位后，仍需核对该段文字能否支持所给结论。
- **应答责任**　程序聚合四态。NC 使用固定口径，UNKNOWN 保留未决原因。人工批准和正式导出由服务端检查。

例如，资料写着「功能需要另购许可证」，可以据此记录许可条件。要承诺本次投标包含许可证，还需要本项目的交付证据。证据准入与正文核验的执行位置见 [RAG](04-RAG.md) 和 [Agent Loop](08-Agent%20Loop.md)。
