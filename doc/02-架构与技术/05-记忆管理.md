# 记忆管理

出版版本：v0.4.6

人工批准应答后，服务端自动生成当前项目的记忆，记录关联的结果、审核与适用信息，便于回查原文、型号和来源。评测模式跳过此步骤。

| 操作 | 处理方式 |
| --- | --- |
| 保存 | 批准后按项目、结果与审核关联，同一关联已有条目时复用 |
| 查阅 | 按项目列出或搜索，从条目追溯结果、依据与审核状态 |
| 启停 | 对当前版本执行变更，记忆页面同时呈现关联记录及来源状态 |

当前主应标流程把记忆作为供人查阅的经验记录。比如过去某一型号的应答已批准，新任务仍根据当前型号、知识版本和条款条件取证。机器结果、人工批准、记忆条目和评测 Gold 各有独立用途。

用于代词指代与追问的消息历史由 [上下文管理](06-上下文管理.md) 处理。写入与管理 · 审核入口
