# Prompt

出版版本：v0.4.6

Laura 按节点生成模型输入。提示词定义每一步要解决的问题，结构化输出由服务端解析，后续节点读取已校验的结果。

## 每次请求的组成

| 组成 | 来源与用途 |
| --- | --- |
| 节点模板 | `prompts/` 中的六项默认模板，分别负责辅助翻译、要求拆分、逐项判定、语义核验、英文口径和产品问答 |
| 共享规则 | 加入系统消息的证据规则，详见 [Skill](02-Skill.md) |
| 输出契约 | 由节点的 Pydantic 类型生成 JSON Schema，例如判定节点返回结论、原因和引用 |
| 本次数据 | 原文、Claim、证据、适用条件和允许的历史字段按节点组织为 `untrusted_data` JSON |

服务端检查节点变量白名单，保留 `NODE` 标记。资料正文作为数据序列化，保留其中的原文、数字与条件。英文口径节点接收已聚合的结论和子项结果，正文与结构化引用分别存放。

## 编辑和版本

设置页以一个配置包显示六项模板和共享规则。保存需要完整字段与预期版本，服务端校验非空、长度并处理并发冲突。有效修改产生版本和内容指纹，任务入队时冻结所用配置。重启恢复沿用原快照，重新创建运行时采用该次入队选定的配置。
