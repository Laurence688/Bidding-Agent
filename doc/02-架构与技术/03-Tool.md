# Tool

出版版本：v0.4.6

Laura 把应标能力接成 Python 工作流节点。图执行器将当前状态传给节点，节点调用检索、规则检查或模型网关，并把结果写回图状态。模型负责结构化判断，宿主持有工具调用权。

| 能力 | 调用路径 | 返回 |
| --- | --- | --- |
| 检索、准入和引用校验 | 节点调用检索器、知识服务和校验函数 | 候选片段、有效引用及排除原因 |
| 翻译、拆分、判断、语义核验、英文口径 | 节点构造 `ModelRequest`，网关调用选定服务并验证 Schema | 结构化输出或错误码 |
| 提交、人工审核、Excel 写入 | 宿主服务按任务、结果及授权状态执行 | 本地持久结果、审核事件或导出产物 |

## 执行顺序与失败

应标主路径按作业、条款、节点和待处理 Claim 串行执行。模型网关对暂态失败按持久预算重试。选定单供应商时最多两次尝试，旧主备快照最多主两次、备一次，备用仍受执行策略约束。鉴权失败与结构不合规返回错误码。普通节点失败记录位置和原因，由条款流程按 UNKNOWN 收口，取消及离线中断由 Worker 接管。

补检是图根据证据缺口触发的业务动作。它将缺口带进检索查询，满足条件的子项才再次判断。工作中心外的离线网络计算器是单独的界面工具，由用户直接操作。
