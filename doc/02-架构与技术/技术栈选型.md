# 技术栈与运行方式

前端采用 React、TypeScript、Vite 与 Ant Design。后端使用 Python、FastAPI 与持久化记录，后台 Worker 执行长任务；SOC 采用固定流程组织要求、检索、证据与判断。资料解析与本地向量索引用于检索，模型网关对接兼容的生成 API。

Windows 便携包内置 Python 3.11.17、Node.js 24.18.0、固定后端依赖与已构建网页，避免普通用户自行安装开发环境；源码包仍需要准备依赖。第三方运行时许可证随包提供。

本地向量模型在首次初始化时下载，构建和查询需使用一致版本。云端生成接口可单独配置；不能把“本地运行网页”理解为生成完全离线。供应商接口与模型可用性以账户权限和当前官方服务为准。
